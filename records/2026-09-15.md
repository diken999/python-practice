# 2026-09-15 · 第8题 · 嵌套字典的展平与还原 (flatten / unflatten)

- 主题: 字典应用
- 难度: 中等

## 📝 题目

### 题目描述

配置中心、埋点上报、表单数据经常是多层嵌套的 dict。为了落库和做 diff, 需要把它拍成一层("打平"), 改完再还原回嵌套结构。

请实现一对互逆函数:

- `flatten(d)`: 把嵌套 dict 打平成单层 dict, 键是"路径字符串"
- `unflatten(flat)`: 把打平过的 dict 还原成嵌套结构

### 输入 / 输出约定

```python
def flatten(d: dict, sep: str = ".") -> dict:
    """把嵌套 dict 打平成单层 dict，sep 连接路径各段。"""

def unflatten(flat: dict, sep: str = ".") -> dict:
    """把 flatten 的结果还原成嵌套 dict。"""
```

`flatten` 规则:

1. 值本身是 `dict` 且**非空** → 继续往下展开, 路径各段用 `sep` 连接。
2. 值**不是** `dict` → 作为叶子原样保留(`None`、`0`、`False`、`""`、`[]` 都算叶子, 不许丢弃)。
3. **空 dict `{}` 视为叶子**, 原样保留为 `{}`(既不展开也不丢)。
4. list / tuple 里嵌套的 dict **不展开**, 整个容器当叶子。
5. 不许修改传入的 `d`(禁止在原地增删键)。

`unflatten` 规则:

6. 按 `sep` 切分路径逐层建 dict, `flatten(unflatten(x)) == x` 对合法输入必须成立。
7. 键是空串、或路径中出现空段(如 `"a..b"`、`"a."`、`".a"`) → 抛 `ValueError`。
8. 前缀冲突: 同一个键既要当叶子又要当中间节点(如同时存在 `"a"` 和 `"a.b"`) → 抛 `ValueError`。
9. 中间节点已经存在但不是 dict(例如先处理了 `"a.b"` 又遇到 `"a.b.c"`, 而 `"a.b"` 的值是 `1`) → 抛 `ValueError`。

实现要求:

- 只用标准库的 dict 操作, **禁止 import json**、禁止第三方库。
- `flatten` 用递归或显式栈都可以, 但嵌套 100 层的输入不能崩。
- `flatten` 返回的 key 顺序: 按原 dict 的插入顺序做深度优先(题目保证 key 均为 str)。

### 样例

**样例 1(基础 + 空 dict 叶子)**

```python
flatten({"a": {"b": 1, "c": {"d": 2}}, "e": 3})
# → {"a.b": 1, "a.c.d": 2, "e": 3}

flatten({"x": {}, "y": {"z": {}}, "n": None})
# → {"x": {}, "y.z": {}, "n": None}

flatten({"a": {"b": 1}}, sep="__")
# → {"a__b": 1}
```

**样例 2(还原 + 往返一致)**

```python
unflatten({"a.b": 1, "a.c.d": 2, "e": 3})
# → {"a": {"b": 1, "c": {"d": 2}}, "e": 3}

unflatten({"x": {}, "y.z": {}})
# → {"x": {}, "y": {"z": {}}}

unflatten({"a_list.0.name": "tom", "a_list.1.name": "amy"}, sep=".")
# → {"a_list": {"0": {"name": "tom"}, "1": {"name": "amy"}}}   # 段一律当字符串键

# 往返: flatten(unflatten(x)) == x
```

**样例 3(非法输入必须抛 ValueError)**

```python
unflatten({"": 1})            # 空键                      → ValueError
unflatten({"a..b": 1})        # 空路径段                  → ValueError
unflatten({"a.": 1})          # 尾随分隔符                → ValueError
unflatten({"a": 1, "a.b": 2}) # a 既是叶子又是中间节点     → ValueError
unflatten({"a.b": 1, "a.b.c": 2})  # b 先是叶子又当中间节点 → ValueError
```

**边界补充**

```python
flatten({})                      # → {}
unflatten({})                    # → {}
flatten({"a": [{"b": 1}]})       # → {"a": [{"b": 1}]}   列表里的 dict 不展开
flatten({"a": {"b": {"c": {"d": 5}}}})
# → {"a.b.c.d": 5}
```

## 💻 我的代码

```python
def flatten(d: dict, sep: str = ".") -> dict:
    """把嵌套 dict 打平成单层 dict，sep 连接路径各段。"""
    result = {}
    def flatten_dict(current_dict: dict, current_path: str):
        for k, v in current_dict.items():
            current_path = k if current_path == "" else current_path + sep + k
            if isinstance(v, dict) and len(v) > 0:
                result[current_path] = flatten_dict(v, current_path)
            else:
                result[current_path] = v
        pass
    for k, v in d.items():
        if isinstance(v, dict) and len(v) > 0:
           flatten_dict(v, "")
        else:
            result[k] = v
    return result

def unflatten(flat: dict,  sep: str = ".") -> dict:
    """把 flatten 的结果还原成嵌套 dict。"""
    result = {}
    def unflatten_dict(key_arr: list, value):
        temp_dict = result
        for idx, key in enumerate(key_arr):
            if key in temp_dict:
                temp_dict = temp_dict[key]
                continue
            if idx != len(key_arr) - 1:
                temp_dict[key] = {}
                temp_dict = temp_dict[key]
            else:
                temp_dict[key] = value

    for k, v in flat.items():
        key_list = k.split(sep)
        if len(key_list) > 1:
            unflatten_dict(key_list, v)
        else:
            result[k] = v
    return result
```

## 💡 改进意见

### flatten 的 3 个 bug

**bug1: 顶层 key 被丢掉**

```python
for k, v in d.items():
    if isinstance(v, dict) and len(v) > 0:
       flatten_dict(v, "")        # ❌ 传空路径, 顶层 key "a" 就没进路径
```

`flatten_dict` 里 `current_path = k if current_path == "" else ...`, 收到空串就把**子键**当整条路径, 于是 `{"a":{"b":1}}` 出来是 `{"b":1}`(应为 `{"a.b":1}`)。初始路径应该带上顶层 key, 或者循环本身就走统一逻辑。

**bug2: 路径变量被兄弟节点污染(最致命)**

```python
def flatten_dict(current_dict, current_path):
    for k, v in current_dict.items():
        current_path = k if current_path == "" else current_path + sep + k   # ❌ 覆写了父路径!
```

`current_path` 是**上一层传来的前缀**, 却在循环里被就地改写。于是同一层的第二个 key 会拼到第一个 key 后面: `{"a":{"b":1,"c":{"d":2}}}` 里 `c` 的路径变成 `"b.c"` 而不是 `"a.c"`, 输出里就出现了 `'b.c'`、`'b.c.d'` 这种畸形成员。

修法: **另用局部变量拼接, 不动父前缀**:

```python
for k, v in current_dict.items():
    path = k if prefix == "" else prefix + sep + k    # 局部 path, prefix 保持不变
```

**bug3: 把递归的返回值当结果(值被写成 None)**

```python
if isinstance(v, dict) and len(v) > 0:
    result[current_path] = flatten_dict(v, current_path)   # ❌ 函数没有 return → 赋值 None
```

`flatten_dict` 没有 `return`, 返回 `None`。它的作用是**往 result 里填东西**, 所以不该接收返回值:

```python
if isinstance(v, dict) and v:
    walk(v, path)          # 只调用, 不赋值
else:
    result[path] = v
```

### flatten 正确写法

```python
def flatten(d: dict, sep: str = ".") -> dict:
    result = {}
    def walk(cur: dict, prefix: str):
        for k, v in cur.items():
            path = k if prefix == "" else prefix + sep + k
            if isinstance(v, dict) and v:      # 非空 dict 才下钻
                walk(v, path)
            else:                              # 叶子: 含 {} / None / list 等
                result[path] = v
    walk(d, "")
    return result
```

要点: `path` 是**每次迭代新建的局部变量**(兄弟互不影响); 递归只负责填 `result`、不返回值; `isinstance(v, dict) and v` 让空 `{}` 落到 else 分支当叶子(正好满足要求3)。

### unflatten 缺了 ValueError 校验(要求7/8/9)

三个样例2 都对, 说明基本建树逻辑没问题; 但非法输入一个都没拦:

- 空键 `"": 1` → 应该直接 `raise ValueError`, 现在原样塞进结果
- 含空段 `"a..b"` / 尾随 `"a."` → `split(sep)` 后有空串**段**, 要检查; 现在把 `""` 当合法键建进去了
- 前缀冲突 / 中间节点非 dict → 现在抛的是 `TypeError`(`int` 不支持 `[]` 赋值), 必须主动判类型并抛 `ValueError`

正确写法:

```python
def unflatten(flat: dict, sep: str = ".") -> dict:
    result = {}
    for key, value in flat.items():
        if key == "":
            raise ValueError(f"空键: {key!r}")
        parts = key.split(sep)
        if any(p == "" for p in parts):
            raise ValueError(f"路径存在空段: {key!r}")
        node = result
        for i, part in enumerate(parts):
            last = (i == len(parts) - 1)
            if last:
                if part in node:                    # 已被占用(叶子或中间节点)
                    raise ValueError(f"前缀冲突: {key!r}")
                node[part] = value
            else:
                if part in node:
                    nxt = node[part]
                    if not isinstance(nxt, dict):   # 中间节点不是 dict
                        raise ValueError(f"中间节点不是 dict: {key!r}")
                    node = nxt
                else:
                    node[part] = {}
                    node = node[part]
    return result
```

关键: 走每一段时**先判合法性再下钻**; 最后一段若已存在 → 前缀冲突; 中间段若已存在但非 dict → 报错。

## ⚠️ 当前问题 / 复盘

- `flatten`: 3 个 bug 叠在一起 —— ①顶层 key 丢失(初始路径传 `""`) ②路径变量在循环里被覆写, 兄弟节点互相污染 ③接收递归返回值, 结果被写成 `None`
- `unflatten`: 建树逻辑正确(样例2 全过)但**完全没做非法输入校验**, 要求7/8/9 五个用例全挂; 前缀冲突时还抛了 `TypeError` 而非题目要求的 `ValueError`
- 往返一致因此全线失败(被 flatten 拖累)
- 教训1: **递归函数的职责要想清楚**——"负责往容器里填"就不该有返回值、更不该把 `None` 接回来当值
- 教训2: **父前缀不能就地改**。树形递归里, 每次迭代/每次递归都要用**新的局部变量**拼当前路径, 拿上一层的前缀当可变累加器必然污染兄弟节点
- 教训3: **题目写"抛 ValueError"就是硬性验收项**, 不能只实现 happy path。这类题目要专门为自己的每个 error 分支写一条测试
