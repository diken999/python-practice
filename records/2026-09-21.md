# 2026-09-21 · 第12题 · 机房巡检看板格式化器

- 主题: 格式化与f-string
- 难度: 中等

## 📝 题目

### 题目描述

巡检系统要把每台设备的原始 dict（字段可能缺失，值也可能是 None）渲染成固定格式的单行文本，再把多台设备拼成一块看板。本题考的就是 f-string 格式说明符 + 缺失值容错。

### 输入 / 输出约定

**签名 1**

```python
def format_probe(rec: dict) -> str
```

`rec` 可能包含：`sn`(int，设备序号，≥0)、`temp`(float|None，温度 ℃)、`load`(float|None，负载率 0~1)、`mem`(int，内存占用字节)、`delta`(float|None，较上次温度变化 ℃)。**key 可能压根不存在**，与值为 `None` 同等处理。

返回单行文本，字段顺序固定，用单个空格分隔：

```
SN=<sn> TEMP=<temp>℃ LOAD=<load> MEM=<mem>B DELTA=<delta>℃
```

字段规则：

1. `SN`：6 位零填充整数，如 42 → `000042`
2. `TEMP`：2 位小数，**非负数必须带 `+` 号**；缺失/None → `N/A`（且不带 `℃`）
3. `LOAD`：比例转百分比，1 位小数，如 0.0837 → `8.4%`；缺失/None → `N/A`
4. `MEM`：`< 1_000_000` 用千分位整数；`>= 1_000_000` 用 3 位小数的科学计数法；缺失/None → `N/A`（且不带 `B`）
5. `DELTA`：2 位小数带符号；缺失/None → `N/A`（且不带 `℃`）

**签名 2**

```python
def format_board(records: list[dict], *, title: str) -> str
```

返回多行文本（`\n` 连接）：

- 第 1 行：`[INSPECT] {title} ({台数} 台设备)`
- 中间：每台设备一行，内容即 `format_probe(rec)`，顺序与入参一致
- 最后一行：`异常: {k} 台`。设备判为异常（任一命中即可）：`temp` 缺失/None 或 `temp >= 60`；`load` 缺失/None 或 `load >= 0.9`
- `records` 为空 → 只返回第 1 行 + `异常: 0 台`

### 样例

样例 1（`format_probe`，含缺失字段/None 边界）：

```
输入: {"sn": 42, "temp": 25.3, "load": 0.0837, "mem": 12345678, "delta": -1.5}
输出: SN=000042 TEMP=+25.30℃ LOAD=8.4% MEM=1.235e+07B DELTA=-1.50℃

输入: {"sn": 7, "temp": None, "load": 0.0, "mem": 999999, "delta": 0}
输出: SN=000007 TEMP=N/A LOAD=0.0% MEM=999,999B DELTA=+0.00℃

输入: {"sn": 1234567, "load": 1.0, "mem": 0}
输出: SN=1234567 TEMP=N/A LOAD=100.0% MEM=0B DELTA=N/A
```

样例 2（`format_board`）：

```python
records = [
    {"sn": 1, "temp": 25.3, "load": 0.0837, "mem": 12345678, "delta": -1.5},
    {"sn": 2, "temp": 61.0, "load": 0.5, "mem": 2048, "delta": 2.25},
    {"sn": 3, "temp": 30.0, "load": 0.92, "mem": 1000000, "delta": 0.0},
]
format_board(records, title="B1机房")
```

输出：

```
[INSPECT] B1机房 (3 台设备)
SN=000001 TEMP=+25.30℃ LOAD=8.4% MEM=1.235e+07B DELTA=-1.50℃
SN=000002 TEMP=+61.00℃ LOAD=50.0% MEM=2,048B DELTA=+2.25℃
SN=000003 TEMP=+30.00℃ LOAD=92.0% MEM=1.000e+06B DELTA=+0.00℃
异常: 2 台
```

样例 3（空列表边界）：

```
输入: format_board([], title="B1机房")
输出: "[INSPECT] B1机房 (0 台设备)\n异常: 0 台"
```

### 实现要求

1. 补零、千分位、科学计数法、百分比、正号**必须用 f-string 格式说明符**（`:06d` / `:,` / `:.3e` / `:.1%` / `:+` 等）实现；禁止 `str.zfill`、`"{}".format()`、`%` 格式化、`round()`、`ljust/rjust/center`。
2. 缺失 key 一律用 `dict.get(key)`，不要 `rec[key]` 硬取（会 KeyError）。
3. 建议先算出每段的"显示文本"（None → `N/A`，并按是否 None 决定要不要后缀 `℃`/`B`），最后一行 f-string 拼接。
4. 返回值不要有多余空格或换行；不得修改入参。
5. 加分项（可选）：把字段格式规则抽成小函数或常量表，`format_board` 只负责拼装与统计。
