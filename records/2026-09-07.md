## 📝 题目

### 题目描述

写一个程序: 从标准输入依次读入三行 —— 姓名、年龄、城市, 然后把它们组装成一句格式化的自我介绍并输出。

输入的三行内容都**可能带首尾空格**(比如粘贴时带进来的缩进), 真正的值要以去掉首尾空格后的内容为准; 年龄那一行读进来是字符串, 要转成整数才能参与格式化。

要求把核心逻辑放进函数 `make_intro`, 方便单独测试。

### 输入 / 输出约定

- 输入: 共 3 行
  1. 姓名 name(str)
  2. 年龄 age(str, 保证是 0~150 的整数, 但需自行转 int)
  3. 城市 city(str)
  - 每行都可能带首尾空白字符, 需 strip; 行**内部**的空格原样保留(比如城市"深圳 龙岗"中间那个空格不能丢)
- 函数签名: `def make_intro(name: str, age: int, city: str) -> str`
  - 返回 `"我是{name}, 今年{age}岁, 来自{city}。"`
- 主程序: 读 3 行 → 处理 → 调 `make_intro` → `print` 返回值

### 样例

样例 1(常规):

```
输入:
小马
26
成都

输出:
我是小马, 今年26岁, 来自成都。
```

样例 2(边界: 行首尾带空格、年龄为 0):

```
输入:
  阿伦  
0
  深圳  龙岗  

输出:
我是阿伦, 今年0岁, 来自深圳  龙岗。
```

样例 3(边界: 名字即职业、城市无多余空格):

```
输入:
程序员老张
35
上海

输出:
我是程序员老张, 今年35岁, 来自上海。
```

### 实现要求

- 必须有 `make_intro` 函数 + `if __name__ == "__main__":` 主入口
- 用 `strip()` 处理首尾空白, 别用 `replace(" ", "")`(那会误删行内空格)
- 年龄必须 `int()` 转换后再传入函数
- 变量命名清晰, 程序能直接 `python3 文件名.py` 运行

## 💻 我的代码

```python
def make_intro(name: str, age: int, city: str) -> str:
    return f"我是{name.strip()}，今年{age}岁，来自{city.strip()}。"


if __name__ == "__main__":
    name = input("请输入名字 ")
    age = int(input("请输入年龄 "))
    city = input("请输入城市 ")
    print(make_intro(name, age, city))
```

## 💡 改进意见

**唯一问题: 输出里的逗号用了中文全角 `，`, 题目约定是英文半角 `,`。**

- 题目要求输出: `我是小马, 今年26岁, 来自成都。`(逗号是半角 `,`)
- 代码实际输出: `我是小马，今年26岁，来自成都。`(逗号是全角 `，`)

如果这是自动判题, 输出比对是逐字符的, 全角/半角不一致会判**答案错误**。

修正一行即可:

```python
def make_intro(name: str, age: int, city: str) -> str:
    return f"我是{name.strip()}, 今年{age}岁, 来自{city.strip()}。"
```

(小贴士: 视觉上中文排版常用全角逗号更美观, 但**做题要以题目输出约定为准**, 判题机不认美观只认字符。)
