# 2026-09-09 · 第1题 · 字符串游程压缩

- 主题: 字符串基础处理
- 难度: 中等

## 📝 题目

### 题目描述

实现一个字符串**游程压缩**(Run-Length Encoding)函数 `compress(s)`:

把字符串中**连续出现**的相同字符压缩成「字符 + 出现次数」的形式。例如 `"aaabbbbc"` 中 `aaa`、`bbbb`、`c` 三段分别记作 `a3`、`b4`、`c1`, 拼接得到压缩串 `"a3b4c1"`。

**只有当压缩后的字符串比原串更短时, 才返回压缩串; 否则返回原字符串本身。** 注意是"更短", 长度相等也算压缩失败。

### 输入 / 输出约定

- 函数签名: `def compress(s: str) -> str`
- 输入: 一个字符串 `s`, 长度 `0 ≤ len(s) ≤ 10^5`, 仅含可打印 ASCII 字符
- **大小写敏感**: `"A"` 与 `"a"` 是不同字符, 各成一段
- 输出: 压缩串(更短时)或原串
- 空串返回空串

### 样例

```python
compress("aabcccccaaa")  == "a2b1c5a3"  # 原 12 字符 → 压缩 8 字符, 更短
compress("abcc")         == "abcc"      # 压缩得 "a1b1c2"(6 字符), 不更短 → 返回原串
compress("AAaa")         == "AAaa"      # 压缩得 "A2a2"(长度相等), 不算更短 → 返回原串
compress("a")            == "a"         # 单字符, 压缩必变长 → 返回原串
compress("")             == ""          # 空串
```

### 实现要求

- 纯手工一次遍历实现, **禁止**使用 `re`、`zlib`、`itertools.groupby`、`collections.Counter` 等现成分组/压缩手段
- 时间 O(n), 空间 O(n)(结果本身占用的空间除外)
- 易错点自查: 连续段的**收尾**(最后一组别忘了结算)、数字多位时的拼接(如 `"c12"`)、压缩收益判断是 `<` 而不是 `<=`
- 不需要处理输入校验

## 💻 我的代码

(第3版: 补上"更短才返回"长度比较, 终版)

```python
def compress(s: str) -> str:
    result = ""
    index = 0
    while index < len(s):
        count = 1
        while index < len(s) - 1 and s[index] == s[index + 1]:
            count += 1
            index += 1
        result += s[index] + str(count)
        index += 1
    return result if len(result) < len(s) else s

if __name__ == "__main__":
    input_string = input()
    print(compress(input_string))
```

## 💡 改进意见

### 核心错误 1: 把"全局字符频率"当成了"连续段压缩"(理解错题意)

你的做法: 统计每个字符**在整个串里出现几次**(字符频率表)
题目要求: 统计每个字符**连续出现的一段**有几段、每段几次

反例就是样例1: `"aabcccccaaa"` 里的 `a` 分**两段**(开头 `aa` 和结尾 `aaa`), 必须分别记 `a2` 和 `a3`。频率表只有"a 一共 5 次"一个数, 丢失了位置/分段信息 → `a5b1c5` ≠ `a2b1c5a3`。

**游程压缩要按"连续段"切分**, 正确思路是滑动窗口/双指针:
- 用 `i` 指向当前段起点, `j` 向右扫到字符变化处, `s[i:j]` 就是一段
- 记 `字符 + str(j-i)`, 然后 `i = j` 处理下一段

### 核心错误 2: 缺少"压缩后更短才返回, 否则返回原串"的判断

题目: 压缩串长度**必须小于**原串才返回压缩串; 长度相等(如 `AAaa` → `A2a2`)或变长(如 `abcc`、`a`)都要返回原串。

你的代码无条件返回压缩串, 漏了长度比较。

### 正确实现参考

```python
def compress(s: str) -> str:
    result = []
    i = 0
    n = len(s)
    while i < n:
        j = i
        while j < n and s[j] == s[i]:
            j += 1
        result.append(s[i] + str(j - i))   # 字符 + 连续次数
        i = j
    compressed = "".join(result)
    # 更短才返回压缩串(严格小于, 相等不算)
    return compressed if len(compressed) < n else s
```

要点:
- 用双指针按连续段切分, 天然处理 `a` 分两段的情况
- 用列表收集再 `join`, 避免字符串 `+=` 的 O(n²)(虽 Python 有优化, 但好习惯)
- 最后比较长度: `<` 不是 `<=`(题目强调)
- 变量名别叫 `map`(会遮蔽内置函数 map), 改成 `result`/`cnt` 等

### 自我检查方法

写完后拿这几个串手推一遍:
- `"aabcccccaaa"` → 段是 a2 | b1 | c5 | a3 → 拼接后 8 < 12 → 返回 `a2b1c5a3`
- `"abc"` → a1b1c1 = 6 字符, 6 > 3 → 返回原串 `abc`
