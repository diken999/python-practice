# 2026-09-07 · 第2题 · 个税计算器(七级超额累进)

- 主题: 条件分支
- 难度: 中等

## 📝 题目

### 题目描述

中国的工资薪金个税按"应纳税所得额"七级超额累进计算:

- 应纳税所得额 = 月收入 − 5000(起征点, 忽略五险一金和专项附加扣除)
- 应缴个税 = 应纳税所得额 × 税率 − 速算扣除数

| 级数 | 应纳税所得额区间 | 税率 | 速算扣除数 |
|---|---|---|---|
| 1 | 不超过 3000 元 | 3% | 0 |
| 2 | 3000 ~ 12000 元 | 10% | 210 |
| 3 | 12000 ~ 25000 元 | 20% | 1410 |
| 4 | 25000 ~ 35000 元 | 25% | 2660 |
| 5 | 35000 ~ 55000 元 | 30% | 4410 |
| 6 | 55000 ~ 80000 元 | 35% | 7160 |
| 7 | 超过 80000 元 | 45% | 15160 |

区间"上限包含在内"(即 3000 整、12000 整归入较低税级)。边界值与高收入大数都可能测到, 别偷懒只写几档。

### 输入 / 输出约定

- 函数签名: `def calc_tax(income: int) -> int`, income 为税前月收入(元), 返回应缴个税(元)
- 主程序: 从标准输入读一行整数 → print(calc_tax(...))
- 全部用整数运算(税率按整数百分数算, 不许引入浮点), 结果一定是整数

### 样例

```
calc_tax(4000)   -> 0        # 不到起征点
calc_tax(8000)   -> 90       # 所得 3000, 恰好卡在第1级上边界
calc_tax(10000)  -> 290
calc_tax(30000)  -> 3590     # 所得 25000, 恰好卡在 20%/25% 档边界
calc_tax(150000) -> 50090    # 顶格 45% 档
```

### 实现要求

- 用 if/elif 链或查表都行, 但边界归属必须正确(≤ 归低档)
- 可读性: 税率表别用 8 层魔法数硬堆, 至少用清晰的结构组织(如区间+速算扣除数的列表/元组)
- `calc_tax` 纯函数可独立测试 + `if __name__ == "__main__":` 主入口

## 💻 我的代码

(第3版: 修正公式 + 读 stdin 后)

```python
def calc_tax(income: int) -> int:
    tax_money = income - 5000
    if tax_money <= 0:
        return 0
    elif tax_money <= 3000:
        return int(tax_money * 3 / 100)
    elif tax_money <= 12000:
        return int(tax_money * 10 / 100 - 210)
    elif tax_money <= 25000:
        return int(tax_money * 20 / 100 - 1410)
    elif tax_money <= 35000:
        return int(tax_money * 25 / 100 -2660)
    elif tax_money <= 55000:
        return int(tax_money * 30 / 100 - 4410)
    elif tax_money <= 80000:
        return int(tax_money * 35 / 100 - 7160)
    else:
        return int(tax_money * 45 / 100 - 15160)

if __name__ == '__main__':
    money = int(input("请输入收入"))
    print(calc_tax(money))
```

## 💡 改进意见

### 1. input() 不要带提示文字(关键!)

`input("请输入收入")` 的提示会写到 stdout, 与结果混在一起。判题机逐字符比对必挂。改成:

```python
money = int(input())     # 不带提示
```

(带提示只适合人肉交互的脚本, 不适合判题场景。交互提示要用也应该走 stderr。)

### 2. 整数除法用 `//` 不是 `/`

Python 3 中 `/` 永远是浮点除法(`10/100` → `0.1` float), `//` 才是整除。

```python
tm * 3 // 100        # 整数: 2500*3//100 = 75
tm * 3 / 100         # 浮点: 2500*3/100 = 75.0 (有舍入风险)
```

### 3. 终版参考(整数运算 + 无提示 + 查表)

```python
BRACKETS = [
    (3000, 3, 0), (12000, 10, 210), (25000, 20, 1410),
    (35000, 25, 2660), (55000, 30, 4410), (80000, 35, 7160),
    (None, 45, 15160),
]

def calc_tax(income: int) -> int:
    tm = income - 5000
    if tm <= 0:
        return 0
    for upper, rate, quick in BRACKETS:
        if upper is None or tm <= upper:
            return tm * rate // 100 - quick
    return 0

if __name__ == '__main__':
    money = int(input())
    print(calc_tax(money))
```
