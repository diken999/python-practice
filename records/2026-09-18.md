# 2026-09-18 · 第11题 · 成绩单容错导入器（自定义异常）

- 主题: 异常处理
- 难度: 中等

## 📝 题目

### 题目描述

学校的成绩录入系统要导入一批手写的成绩记录, 一行一个学生, 格式为 `姓名:分数`。
真实数据总是脏的: 有人只写了名字忘了打分, 有人的分数写成了字母, 有人把分数填成了 120, 还有同一个学生被录了两次。

请实现一个**容错导入器**: 单行出错不影响其他行, 错误行逐条记录下来返回, 而不是让程序崩掉。
同时为了调试, 还要支持 `strict=True` 的严格模式: 一遇到错误就立刻抛异常、终止整个导入。

### 输入 / 输出约定

函数签名(名字、参数、返回类型都要一致):

```python
def import_scores(lines: list[str], strict: bool = False) -> tuple[dict[str, float], list[tuple[int, str]]]:
    ...
```

- `lines`: 待导入的原始行, 行号从 **1** 开始计数
- 返回 `(scores, failures)`:
  - `scores`: `{姓名: 分数}`, 分数统一为 `float`, 只包含导入成功的行
  - `failures`: 出错行列表, 每项为 `(行号, 原因)`; 原因只能取三个固定字符串: `"格式错误"` / `"分数超范围"` / `"姓名重复"`
  - `failures` 按行号升序

每行的校验顺序(从前往后, 命中即停 —— 这决定了"姓名重复"和"分数超范围"同时命中时算哪种错):

1. 用 `split(":")` 拆分, **必须恰好 2 段**, 否则 `"格式错误"`(没有冒号、多个冒号都算)
2. 姓名 `strip()` 后不能为空, 否则 `"格式错误"`
3. 分数部分必须能转成 `float`(允许前后空白), 否则 `"格式错误"`
4. 分数必须在 `0 ~ 100` 闭区间内, 否则 `"分数超范围"`
5. 姓名若已存在于 `scores`, 算 `"姓名重复"` —— **保留首次出现的分数, 后出现的整行丢弃**

异常要求:

- 自定义异常层次: 基类 `ScoreImportError`, 三个子类 `FormatError` / `RangeError` / `DuplicateError` 分别对应上面三种原因, 全部继承 `ScoreImportError`
- `lines` 为空列表时整体失败, 抛 `ScoreImportError`(信息不限)
- 第 3 步 `float()` 失败时, 必须用 `raise ... from` 把原始 `ValueError` 作为 `__cause__` 保留下来
- 非严格模式下每行独立捕获, 某一行的异常不能让整个循环中断
- `strict=True` 时遇到第一个错误行立即抛出对应异常(不再返回), 样例 3 会检查 `__cause__`

### 样例

**样例 1 · 混合脏数据(默认容错模式)**

```python
lines = [
    "小明:88",       # 1 正常
    " 小红 : 92.5 ", # 2 正常(姓名与分数两端空白应被忽略)
    "小明:70",       # 3 姓名重复
    "小李",          # 4 格式错误(没有冒号)
    "小张:",         # 5 格式错误(分数为空)
    ":80",           # 6 格式错误(姓名为空)
    "小王:120",      # 7 分数超范围
    "小赵:-5",       # 8 分数超范围
    "小钱:0",        # 9 正常(下边界)
    "小孙:100",      # 10 正常(上边界)
]
scores, fail = import_scores(lines)
print(scores)
print(fail)
```


### 实现要求

1. 函数名 / 参数 / 返回类型严格照签名; 异常类名也必须一致
2. 非严格模式必须**逐行**捕获(每行独立 `try`), 不许把整个循环包在一个 `try` 里
3. 第 3 步的转换必须写成 `try / except ValueError as e / raise FormatError(...) from e`, 不许用 `str.isdigit()`、`try: float(x) except: pass` 之类绕过异常链
4. 范围检查(第 4 步)请放在转换的 `try / except / else` 的 **else** 分支里(转换成功后才做范围检查)
5. 不得修改传入的 `lines`(不 mutate); 函数内部不 print
6. `failures` 里三个原因字符串必须与样例完全一致(方便对照), 异常对象的 `str(e)` 内容不限
7. 顺手写几行自测更好(非必须)

## 💻 我的代码

```python
def parse_record(item: str) -> tuple[str, float]:
    if item.count(":") != 1:
        raise FormatError('格式错误')
    name, score_str = item.split(':', 1)
    name = name.strip()
    score_str = score_str.strip()
    if name == "" or score_str == "":
        raise FormatError('格式错误')
    try:
        score = float(score_str)
    except ValueError as e:
        raise FormatError('格式错误') from e
    if score < 0 or score > 100:
        raise RangeError('分数超范围')
    return name, score


def import_scores(lines: list[str], strict: bool = False) -> tuple[dict[str, float], list[tuple[int, str]]]:
    result = {}
    fail_list = []
    if len(lines) == 0:
        raise ScoreImportError
    for idx, item in enumerate(lines):
        try:
            name, score = parse_record(item)
            if name in result:
                raise DuplicateError('姓名重复')
            result[name] = score

        except ScoreImportError as e:
            if strict == True:
                raise
            else:
                fail_list.append((idx + 1, str(e)))
                continue

    return (result, fail_list)


class ScoreImportError(Exception):
    """分数导入的基础异常"""
    pass
class FormatError(ScoreImportError):
    """数据格式错误"""
    pass
class RangeError(ScoreImportError):
    """分数超出合理范围"""
    pass
class DuplicateError(ScoreImportError):
    """存在重复分数记录"""
    pass
```

## 💡 改进意见

### 已修复: `raise ... from e` 补上了, `__cause__` 正确

第3版把转换包成:

```python
try:
    score = float(score_str)
except ValueError as e:
    raise FormatError('格式错误') from e      # ✅ 显式 from
```

`__cause__` 实测已是 `ValueError` ✅(上一版是 `NoneType`)。

回顾这个坑: **`__context__` ≠ `__cause__`** —— 在 `except` 块里 `raise` 新异常, Python 只会自动挂 `__context__`(隐式链); 只有显式 `from e` 才设 `__cause__`。题目要求3 点名要 `__cause__`, 所以 `from` 省不得。

### 小提示(不影响判题)

- 题目要求4 点名"范围检查放进 `try/except/else` 的 **else** 分支"(含义: 转换成功后才查范围)。你把 `if score < 0 or score > 100` 放在 try/except **之后**, 功能完全等价, 只是不是题目点名的那个写法:

```python
try:
    score = float(score_str)
except ValueError as e:
    raise FormatError("格式错误") from e
else:
    if not (0 <= score <= 100):     # 挪进 else 即符合要求4 的字面要求
        raise RangeError("分数超范围")
```

- 抽出 `parse_record` 是好设计(单一职责、方便单测), 顺带让 `import_scores` 主循环只剩"重复检查 + 收账", 比 v1/v2 清爽很多 👍

### 其它小点

- **裸 `except:` 是坏习惯**: 会连 `KeyboardInterrupt`、`SystemExit` 一起吞掉, 应写明 `except ValueError:`
- `if strict == True:` → `if strict:`(布尔直接用)
- `else: ...; continue` 里的 `continue` 是多余的(已到循环体末尾)
- `return (result, fail_list)` 的括号可省: `return result, fail_list`
- `raise ScoreImportError` → 建议带上信息 `raise ScoreImportError("输入为空")`, 便于调试(题目对信息不限)
- 异常类建议前置到文件开头(`FormatError` 等定义在函数后面, 运行时能用, 但可读性差)

### 完整正确写法

```python
class ScoreImportError(Exception):
    """分数导入的基础异常"""
    pass

class FormatError(ScoreImportError):
    """数据格式错误"""
    pass

class RangeError(ScoreImportError):
    """分数超出合理范围"""
    pass

class DuplicateError(ScoreImportError):
    """存在重复分数记录"""
    pass


def import_scores(lines: list[str], strict: bool = False) -> tuple[dict[str, float], list[tuple[int, str]]]:
    if not lines:                                    # 空列表整体失败
        raise ScoreImportError("输入为空")

    result = {}
    failures = []

    for idx, raw in enumerate(lines, start=1):       # 行号从 1 开始
        try:
            parts = raw.split(":")                   # 必须恰好 2 段
            if len(parts) != 2:
                raise FormatError("格式错误")

            name = parts[0].strip()
            score_str = parts[1].strip()
            if name == "":
                raise FormatError("格式错误")

            try:
                score = float(score_str)             # 允许前后空白
            except ValueError as e:
                raise FormatError("格式错误") from e  # 保留 __cause__
            else:
                if not (0 <= score <= 100):          # 范围检查放 else
                    raise RangeError("分数超范围")

            if name in result:                       # 已存在 → 保留首次
                raise DuplicateError("姓名重复")

            result[name] = score                     # 通过全部检查才写入

        except ScoreImportError as e:
            if strict:
                raise                                # 严格模式: 立即抛出
            failures.append((idx, str(e)))           # 容错: 记录行号+原因

    return result, failures
```
