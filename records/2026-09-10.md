# 2026-09-10 · 第5题 · 会议时段合并(区间合并)

- 主题: 列表操作
- 难度: 中等

## 📝 题目

### 题目描述

会议室预约系统里, 同一间会议室一天内会收到很多零散预约时段, 有些时段互相重叠、有些首尾相接。为了生成"实际占用时段表", 需要把所有**重叠或端点相接**的时段合并成尽量少的连续时段。

给定一个二维列表 `intervals`, 每个元素形如 `[start, end]` 表示一个时间段(整数时间戳, 保证 `start <= end`)。
请把所有**有重叠**或**端点相接**的时段合并, 返回合并后的时段列表(按开始时间升序)。

约定: 若前一时段的 `end >= 后一时段的 start`, 即使只是端点相碰(如 `[1,4]` 与 `[4,5]`), 也算连续, 必须合并。

### 输入 / 输出约定

- 函数签名: `def merge_intervals(intervals: list[list[int]]) -> list[list[int]]`
- `intervals`: 二维整数列表, 内部元素是长度为 2 的 `[start, end]`, 且 `start <= end`; 输入**可能无序**, 也可能为空列表
- 返回: **新的**二维列表, 每个元素是合并后的 `[start, end]`, 按 `start` 升序
- 输入为空时返回 `[]`
- **不得修改传入的 `intervals`**(包括它的内层列表): 调用前后 `intervals` 必须完全一致

### 样例

```python
# 1. 常规重叠
merge_intervals([[1, 3], [2, 6], [8, 10], [15, 18]])
# → [[1, 6], [8, 10], [15, 18]]

# 2. 端点相接(只有接点没有重叠)也要合并
merge_intervals([[1, 4], [4, 5]])
# → [[1, 5]]

# 3. 被完全包含的区间
merge_intervals([[1, 10], [2, 3], [4, 8]])
# → [[1, 10]]

# 4. 边界: 空输入
merge_intervals([])
# → []

# 5. 边界: 乱序输入
merge_intervals([[5, 6], [1, 3]])
# → [[1, 3], [5, 6]]

# 6. 边界: 点区间 + 链条式相接
merge_intervals([[1, 1], [1, 2], [3, 3]])
# → [[1, 2], [3, 3]]
```

### 实现要求

1. 允许使用 `sorted` / `min` / `max` 等常用内置函数; 不允许引入第三方库, 也不要用 `itertools.groupby` 之类整段式快捷写法, 合并逻辑自己写。
2. 实现"读一个区间、与已合并结果末尾比较"的单次线性扫描思路, 目标复杂度 **O(n log n)** 时间(排序主导)、**O(n)** 额外空间(不含返回值)。
3. 返回的每个区间必须是**新构造的 `list`**, 不能直接复用输入的内层列表对象(否则会踩"修改输入"的坑)。
4. 必须覆盖以下五类情况: 空列表、乱序输入、区间相互包含、端点相接、单点区间(`start == end`)。
5. 请在代码里保留函数名与签名, 另外写一小段 `if __name__ == "__main__":` 跑上面 6 个样例并打印结果。

## 💻 我的代码

(第2版 · 终版)

```python
def merge_intervals(intervals: list[list[int]]) -> list[list[int]]:
    if len(intervals) == 0:
        return []
    ordered = sorted(intervals, key = lambda x: x[0])
    result_list = [[ordered[0][0], ordered[0][1]]]
    for item in ordered:
        last_item = result_list[-1]
        if item[0] <= last_item[1]:
            result_list[-1] = [min(item[0], last_item[0]), max([item[1], last_item[1]])]
        else:
            result_list.append([*item])
    return result_list

if __name__ == "__main__":
    print(merge_intervals([[1, 3], [2, 6], [8, 10], [15, 18]]))
    print(merge_intervals([[1, 4], [4, 5]]))
    print(merge_intervals([[1, 10], [2, 3], [4, 8]]))
    print(merge_intervals([]))
    print(merge_intervals([[5, 6], [1, 3]]))
    print(merge_intervals([[1, 1], [1, 2], [3, 3]]))
```

## 💡 改进意见

思路和正确性都达标了, 以下是锦上添花(不影响判题):

### 1. 循环可以从 `ordered[1:]` 开始(省一次冗余比较)

`result_list` 已经用 `ordered[0]` 初始化了, 但 `for item in ordered:` 又会把 `ordered[0]` 再处理一遍——第一轮是"自己和自己比"(恒成立), 无害但多余:

```python
for item in ordered[1:]:
```

### 2. `min` 可以省掉

序列已按 `x[0]` 排序, 所以 `item[0] >= last_item[0]` 恒成立, `min(item[0], last_item[0])` 永远是 `last_item[0]`:

```python
result_list[-1] = [last_item[0], max(item[1], last_item[1])]
```

### 3. `max` 别传 list

`max([item[1], last_item[1]])` 是先造一个临时 list 再求最大值, 直接传两个参数即可(更省且更地道):

```python
max(item[1], last_item[1])
```

### 4. 可选: 更像题目提示的写法

题目要求2的提示是"与已合并结果**末尾**比较", 直接就地更新末尾的 `end` 更直观:

```python
def merge_intervals(intervals: list[list[int]]) -> list[list[int]]:
    if not intervals:
        return []
    ordered = sorted(intervals, key=lambda x: x[0])
    result = [[ordered[0][0], ordered[0][1]]]
    for start, end in ordered[1:]:
        if start <= result[-1][1]:
            result[-1][1] = max(result[-1][1], end)
        else:
            result.append([start, end])
    return result
```

### 5. 风格小点

- `key = lambda x: x[0]` 里的空格(PEP8 建议关键字参数不加空格): `key=lambda x: x[0]`
- `[*item]` 能工作, 但 `item[:]` 或 `[item[0], item[1]]` 更常见
