# 2026-09-10 · 第5题 · 会议时段合并(区间合并)

- 主题: 列表操作
- 难度: 中等

## 📝 题目

### 题目描述

会议室预约系统里, 同一间会议室一天内会收到很多零散预约时段, 有些时段互相重叠、有些首尾相接。为了生成"实际占用时段表", 需要把所有**重叠或端点相接**的时段合并成尽量少的连续时段。

给定一个二维列表 `intervals`, 每个元素形如 `[start, end]` 表示一个时间段(整数时间戳, 保证 `start <= end`)。
请把所有**有重叠**或**端点相接**的时段合并, 返回合并后的时段列表(按开始时间升序)。

约定: 若前一时段的 `end >= 后一时段的 start`, 即使只是端点相碰(如 `[1,4]` 与 `[4,5]`), 也算连续, 必须合并。

### 输入 / 输出约定

- 函数签名: `def merge_intervals(intervals: list[list[int]]) -> list[list[int]]`
- `intervals`: 二维整数列表, 内部元素是长度为 2 的 `[start, end]`, 且 `start <= end`; 输入**可能无序**, 也可能为空列表
- 返回: **新的**二维列表, 每个元素是合并后的 `[start, end]`, 按 `start` 升序
- 输入为空时返回 `[]`
- **不得修改传入的 `intervals`**(包括它的内层列表): 调用前后 `intervals` 必须完全一致

### 样例

```python
# 1. 常规重叠
merge_intervals([[1, 3], [2, 6], [8, 10], [15, 18]])
# → [[1, 6], [8, 10], [15, 18]]

# 2. 端点相接(只有接点没有重叠)也要合并
merge_intervals([[1, 4], [4, 5]])
# → [[1, 5]]

# 3. 被完全包含的区间
merge_intervals([[1, 10], [2, 3], [4, 8]])
# → [[1, 10]]

# 4. 边界: 空输入
merge_intervals([])
# → []

# 5. 边界: 乱序输入
merge_intervals([[5, 6], [1, 3]])
# → [[1, 3], [5, 6]]

# 6. 边界: 点区间 + 链条式相接
merge_intervals([[1, 1], [1, 2], [3, 3]])
# → [[1, 2], [3, 3]]
```

### 实现要求

1. 允许使用 `sorted` / `min` / `max` 等常用内置函数; 不允许引入第三方库, 也不要用 `itertools.groupby` 之类整段式快捷写法, 合并逻辑自己写。
2. 实现"读一个区间、与已合并结果末尾比较"的单次线性扫描思路, 目标复杂度 **O(n log n)** 时间(排序主导)、**O(n)** 额外空间(不含返回值)。
3. 返回的每个区间必须是**新构造的 `list`**, 不能直接复用输入的内层列表对象(否则会踩"修改输入"的坑)。
4. 必须覆盖以下五类情况: 空列表、乱序输入、区间相互包含、端点相接、单点区间(`start == end`)。
5. 请在代码里保留函数名与签名, 另外写一小段 `if __name__ == "__main__":` 跑上面 6 个样例并打印结果。

## 💻 我的代码

```python
def merge_intervals(intervals: list[list[int]]) -> list[list[int]]:
    result_list = []
    for item in intervals:
        if len(result_list) == 0:
            result_list.append(item)
        else:
            is_in_list = False
            for res_index, res_item in enumerate(result_list):
                if item[0] >= res_item[0] and item[1] <= res_item[1]:
                    is_in_list = True
                    break
                if item[1] < res_item[0] or item[0] > res_item[1]:
                    continue
                if item[0] >= res_item[0] or item[1] <= res_item[1]:
                    result_list[res_index] = [min(item[0], res_item[0]), max(item[1], res_item[1])]
                    is_in_list = True
                    break
            if is_in_list == False:
                result_list.append(item)
    return sorted(result_list, key=lambda x: x[0])

if __name__ == "__main__":
    print(merge_intervals([[1, 3], [2, 6], [8, 10], [15, 18]]))
    print(merge_intervals([[1, 4], [4, 5]]))
    print(merge_intervals([[1, 10], [2, 3], [4, 8]]))
    print(merge_intervals([]))
    print(merge_intervals([[5, 6], [1, 3]]))
    print(merge_intervals([[1, 1], [1, 2], [3, 3]]))
```

## 💡 改进意见

### 问题1: 区间被"完全包住但方向相反"时不合并

`[[2,3],[1,4]]`: 先放 `[2,3]`, 再到 `[1,4]` 时:
- 第1个 if(在内部): `1>=2 and 4<=3` → False
- 第2个 if(不相交): `4<2 or 1>3` → False
- 第3个 if: `1>=2 or 4<=3` → **False**(`[1,4]` 两端都在 `[2,3]` 外面)
- 三个分支全不中 → 当成"独立区间" append → 合并失败

问题根源: 把"相交"判断写成 `item[0] >= res_item[0] or item[1] <= res_item[1]`, 用 `or` 覆盖不全, 漏掉了"新区间把旧区间整个包住"的情形。

### 问题2: 合并后没有连锁再检查

`[[1,2],[3,4],[2,3]]`: `[2,3]` 与 `[1,2]` 合并成 `[1,3]` 后 `break`, 但没再和结果里的 `[3,4]` 比对(`[1,3]` 与 `[3,4]` 端点相接应继续合并成 `[1,4]`)。这是"边合并边漏检"的典型 bug。

### 问题3: 返回复用了输入的内层列表对象

`result_list.append(item)` 里的 `item` 就是 `intervals` 里的原列表。不合并时直接把原对象塞进结果, 违反"每个区间必须是新构造的 list"。应 `append([item[0], item[1]])` 或 `append(item[:])`。

### 问题4: 没按题目建议的思路做

题目要求2明确提示"读一个区间、与已合并结果**末尾**比较的单次线性扫描"。你的写法是"每个新区间与结果里**所有**已有区间逐一比对"(嵌套循环), 复杂度 O(n²), 且逻辑分支多、易错。

### 正确解法(排序 + 与末尾比较, O(n log n))

```python
def merge_intervals(intervals: list[list[int]]) -> list[list[int]]:
    if not intervals:
        return []
    # 排序用复制, 不动原输入
    ordered = sorted(intervals, key=lambda x: x[0])
    result = [[ordered[0][0], ordered[0][1]]]   # 新构造的 list
    for start, end in ordered[1:]:
        if start <= result[-1][1]:              # 与末尾重叠/相接(start==尾部end 也要合)
            result[-1][1] = max(result[-1][1], end)
        else:
            result.append([start, end])         # 新构造的 list
    return result
```

要点:
- 先按 `start` 排序 → 所有重叠/相接的区间必然相邻 → 只需与**末尾**比较(这就是题目提示的思路)
- `start <= result[-1][1]`: 端点相接(`start == 末尾end`)也满足 `<=`, 自动合并
- 合并时更新末尾的 `end` 取 `max`; 不合并则 append **新列表**
- 全程不改输入: 排序用 `sorted`(返回新列表), 内层用 `[start, end]` 新建

## ⚠️ 当前问题 / 复盘

- 教训: **样例全过 ≠ 正确**。官方 6 样例都是"大区间在前 / 区间基本有序"的友好数据, 掩盖了"大区间在后"和"连锁合并"两类 bug。要自己补: 逆序、嵌套、链条相接等对抗性数据
- 另一教训: "返回新对象、不碰输入"在 Python 里要靠**显式构造新 list**(`[a,b]` 或 `x[:]`), `append(原对象)` 是隐蔽的引用复用
- 待办: 换成"排序+与末尾比较"的标准写法, 才同时满足正确性与 O(n log n)
