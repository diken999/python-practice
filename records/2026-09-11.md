# 2026-09-11 · 第6题 · 奇偶洗牌的最少复原次数

- 主题: 切片与步长
- 难度: 中等

## 📝 题目

### 题目描述

定义一个列表的"奇偶洗牌"操作 `shuffle_once(nums)`:

- 取出所有**偶数下标**(0, 2, 4, ...)上的元素, 按原来的先后顺序排在前面;
- 再取出所有**奇数下标**(1, 3, 5, ...)上的元素, 按原来的先后顺序排在后面;
- 拼接成一个**新列表**返回(原列表保持不变)。

例如 `[1, 2, 3, 4, 5, 6]` 洗一次得到 `[1, 3, 5, 2, 4, 6]`。

现在对同一个列表反复施加这个操作, 要求求出**最小的正整数 k**, 使得连续执行 k 次洗牌后, 得到的列表与初始列表**逐个位置完全相同**(是同一个序列, 不是"元素集合相同")。

### 输入 / 输出约定

- `shuffle_once(nums: list) -> list`: 返回一次洗牌后的新列表, **不修改入参**; 核心取数逻辑必须用**切片(含步长)**实现, 不允许用 for 循环逐个判断下标再 append。
- `min_steps(nums: list) -> int`: 返回最小的正整数 k, 题目保证这样的 k 一定存在。
- `1 <= len(nums) <= 3000`, 元素为整数(可能重复, 可能为正/负/0)。
- 单次 `min_steps` 调用要求在 1 秒内返回。

### 样例

```python
# 1) 一次洗牌的基本形态
shuffle_once([1, 2, 3, 4, 5, 6])   # [1, 3, 5, 2, 4, 6]
shuffle_once([])                   # []
shuffle_once([9])                  # [9]

# 2) 长度为 4: [1,2,3,4] -> [1,3,2,4] -> [1,2,3,4]
min_steps([1, 2, 3, 4])            # 2

# 3) 边界: 长度为 1 / 2
min_steps([7])                     # 1  (洗一次还是 [7])
min_steps([1, 2])                  # 1  (洗一次就变回 [1,2])

# 4) 长度为 3 / 5 / 6
min_steps([1, 2, 3])               # 2
min_steps([1, 2, 3, 4, 5])         # 4
min_steps([1, 2, 3, 4, 5, 6])      # 4

# 5) 陷阱: 元素有重复值, 不能用集合/排序后的结果比较
min_steps([1, 1, 2, 2])            # 2
```

### 实现要求

1. `shuffle_once` 用切片一步取偶数位 `nums[::2]`、奇数位 `nums[1::2]` 拼接, 不能循环筛选; 返回新列表, 入参不得被改动(验收会检查调用后原列表不变)。
2. `min_steps` 必须真的对序列做逐位置比较来判断"复原", 模拟或数学推导都行, 但要对任意长度都正确 —— 尤其注意**元素重复**和**长度为奇数**的情况。
3. 自己写好 `if __name__ == "__main__":` 的自测, 把上面 5 组样例都跑一遍。
4. 复杂度不要求最优, 但 3000 长度要跑得动(别每次递归复制出指数级的列表)。

## 💻 我的代码

```python
def shuffle_once(nums: list) -> list:
    even =  nums[1::2]
    odd = nums[::2]
    return odd + even

def is_same(nums_1: list, nums_2: list) -> bool:
    flag = True
    if len(nums_1) != len(nums_2):
        return False
    for idx, it in enumerate(nums_1):
        if it != nums_2[idx]:
            flag = False
    return flag

def min_steps(nums: list) -> int:
    steps = 1
    shuffle_list = shuffle_once(nums)
    while is_same(nums, shuffle_list) == False:
        shuffle_list = shuffle_once(shuffle_list)
        steps += 1
    return steps

if __name__ == "__main__":
    print(shuffle_once([1, 2, 3, 4, 5, 6])) # [1, 3, 5, 2, 4, 6]
    print(min_steps([1, 2, 3, 4]))            # 2
    print(min_steps([7]))                   # 1
    print(min_steps([1, 2]))                  # 1
    print(min_steps([1, 2, 3]))               # 2
    print(min_steps([1, 2, 3, 4, 5]))         # 4
    print(min_steps([1, 2, 3, 4, 5, 6]))      # 4
    print(min_steps([1, 1, 2, 2]))
```

## 💡 改进意见

功能完全正确, 这题一次到位! 以下是锦上添花的小建议(不影响判题):

### 1. 变量命名反了(可读性)

```python
even = nums[1::2]   # 这是【奇数下标】的元素, 命名成 even 会误导
odd = nums[::2]     # 这是【偶数下标】的元素, 命名成 odd 会误导
```

两个名字恰好都反了, 所以 `odd + even` = 偶下标 + 奇下标, 结果碰巧对。但读代码的人会晕。改成:

```python
even_pos = nums[::2]    # 偶数下标
odd_pos = nums[1::2]    # 奇数下标
return even_pos + odd_pos
```

### 2. is_same 可提前返回(更清晰高效)

```python
def is_same(a: list, b: list) -> bool:
    if len(a) != len(b):
        return False
    for x, y in zip(a, b):
        if x != y:
            return False        # 一发现不同就返回, 不必扫完
    return True
```

用 `zip` 同时遍历两个列表比 `enumerate` 取下标更 Pythonic; 找到不同立刻 `return False` 比 `flag` 变量更直观。

### 3. 一点算法补充(了解即可)

本题用"模拟 + 逐次比较"完全达标(O(n·k), k=阶数, n=3000 时 0.15s)。若长度更大(如 10^7), 可改用**数学法**: 洗牌是下标的一个置换, 复原次数 = 该置换所有循环长度的最小公倍数, 可在 O(n) 内直接算出。当前题目 n≤3000, 模拟法是最稳的选择, 无需改。
