# 2026-09-14 · 第7题 · 传感器读数汇总与元组首尾解包

- 主题: 元组与解包
- 难度: 中等

## 📝 题目

### 题目描述

某采集系统把每条传感器记录存成一个元组, 形状固定为 `(sid, v1, v2, ..., vn)`:

- 第 1 个元素 `sid` 是设备名(字符串), 后面跟着 **0 个或多个** 整数读数;
- 同一个设备可能出现多条记录, 需要合并统计;
- 元组不可变, 所有"修改"都要靠**重新构造新元组**完成。

请实现两个函数:

1. `rotate_ends(record)`: 把一条记录里**读数的首尾互换**, 中间的读数保持原序, `sid` 不动, 返回一个**新的元组**(长度与输入相同)。若读数个数少于 2 个, 读数部分原样保留。
2. `summarize(records)`: 合并统计所有记录, 按 `sid` **首次出现顺序**输出列表, 每个元素为元组 `(sid, count, total, avg)`。

### 输入 / 输出约定

```python
def rotate_ends(record: tuple) -> tuple:
    """
    record: (sid, v1, ..., vn), sid 为 str, vi 为 int, n >= 0
    返回: 新的元组 (sid, ...), 读数的第 1 个与最后 1 个互换, 其余保持原序
          n < 2 时读数部分不变
    """

def summarize(records) -> list:
    """
    records: 可迭代对象, 元素为 (sid, v1, ..., vn) 形式的元组
    返回: 列表, 每项 (sid, count, total, avg)
      count —— 该设备所有记录里读数的总个数
      total —— 该设备所有读数的总和, 用 int
      avg   —— round(total / count, 2); count == 0 时 avg 为 0.0 (不允许除零报错)
    空输入返回 []
    返回的元组元素类型: (str, int, int, float)
    """
```

### 样例

**样例 1 — 主流程(合并 + 首尾互换)**

```python
>>> rotate_ends(("A", 1, 2, 3, 4))
('A', 4, 2, 3, 1)

>>> summarize([("A", 1, 2, 3, 4), ("B", 10), ("A", 5, 6)])
[('A', 6, 21, 3.5), ('B', 1, 10, 10.0)]
# A: 读数 1,2,3,4,5,6 → count=6, total=21, avg=3.5, 且排在最前(首次出现)
# B: count=1, total=10, avg=10.0
```

**样例 2 — 边界: 无读数 / 负数 / 空输入**

```python
>>> rotate_ends(("B", 7))
('B', 7)
>>> rotate_ends(("C",))
('C',)

>>> summarize([("X",), ("Y", 0, 0), ("X", -3)])
[('X', 1, -3, -3.0), ('Y', 2, 0, 0.0)]
>>> summarize([])
[]
>>> summarize([("Z",)])
[('Z', 0, 0, 0.0)]
```

**样例 3 — 取整与不修改原对象**

```python
>>> summarize([("Z", 1, 2, 2)])
[('Z', 3, 5, 1.67)]          # round(5/3, 2)

>>> r = ("A", 1, 2, 3, 4)
>>> rotate_ends(r)
('A', 4, 2, 3, 1)
>>> r
('A', 1, 2, 3, 4)            # 原元组不受影响
```

### 实现要求

1. 两个函数都必须用**元组解包**来处理结构, 不允许用下标去抠:
   - `rotate_ends` 里禁止出现 `record[0]` / `vals[-1]` / `vals[0]` 这类取值, 必须用一次形如 `sid, *mid, last = record` 的星号解包完成首尾互换;
   - `summarize` 里用 `for sid, *vals in records` 遍历。
2. `summarize` 用 dict 累计(新版本 Python 的 dict 天然保留插入顺序), 不要额外排序, 输出顺序 = 首次出现顺序。
3. 全程只用标准库, 不引入第三方包; 元组不可变, 别硬凑原地修改。
4. `count == 0` 的分支必须显式处理, 不能让 `ZeroDivisionError` 冒出来。
5. 目标: 30 分钟内写完, 写完自己先跑一遍上面 3 个样例。

## 💻 我的代码

(第3版 · 终版)

```python
def rotate_ends(record: tuple) -> tuple:
    sid, *arr = record
    if len(arr) < 2:
        return (sid, *arr)
    else:
        first, *center, last = arr
    return (sid, last, *center, first)

def summarize(records) -> list:
    result = []
    records_map = {}
    for index, item in enumerate(records):
        sid, *arr = item
        if sid in records_map:
           old_index = records_map[sid]
           old_item = result[old_index]
           count = len(arr) + old_item[1]
           total = sum(arr) + old_item[2]
           avg = round(total / count, 2)
           result[old_index] = (sid, count, total, avg)
        else :
            count = len(arr)
            total = sum(arr)
            avg = round(total / count, 2) if count != 0 else 0.0
            result.append((sid, count, total, avg))
            records_map[sid] = len(result) - 1
    return result
```

## 💡 改进意见

功能全部正确! 两处修复到位(`else 0.0`、`records_map[sid] = len(result) - 1`)。以下是可选打磨:

### 1. 纯 dict 写法更短(题目要求2的本意)

当前用 `result` + `records_map` 两个结构维护, 能跑对但绕。题目要求2就是"用 dict 累计", 可简化成:

```python
def summarize(records) -> list:
    stats = {}                       # sid -> [count, total]
    for sid, *vals in records:
        if sid not in stats:
            stats[sid] = [0, 0]
        stats[sid][0] += len(vals)
        stats[sid][1] += sum(vals)
    return [
        (sid, c, t, round(t / c, 2) if c else 0.0)
        for sid, (c, t) in stats.items()
    ]
```

好处: 不用 `enumerate`、不用维护下标映射, 从根上杜绝"下标错位"这类 bug。

### 2. rotate_ends 可压平(非必需)

`if/else` 里做解包、`return` 放分支外, 稍绕; 平铺版:

```python
def rotate_ends(record: tuple) -> tuple:
    if len(record) < 2:
        return record
    sid, *mid, last = record
    if not mid:
        return (sid, last)
    return (sid, last, *mid[1:], mid[0])
```

### 3. 小细节

- `else :` 前的空格(冒号前多一个空格)是无害的, 但风格上没人这么写, 可去掉
- `for index, item in enumerate(records)` 里 `index` 现在只用于 `records_map` 赋值, 若采纳纯 dict 写法可省
