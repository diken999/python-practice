# 2026-09-16 · 第9题 · 好友推荐榜（共同好友打分）

- 主题: 集合应用
- 难度: 中等

## 📝 题目

### 题目描述

给定一张社交关系表 `relations`，每条关系形如 `"A-B"`，表示 A 与 B 是好友。请为指定用户 `target` 生成"推荐好友榜"。

规则：

1. 关系一律按**无向**处理：`"A-B"` 与 `"B-A"` 等价；同一条关系重复出现只算一次；`"A-A"`（自己加自己）视为无效，直接忽略。
2. 候选人 = target 直接好友的直接好友，再减去 target 自己和 target 已有的好友。
3. 每位候选人的**推荐分 = 共同好友数**，共同好友 = `target的好友集合 ∩ 该候选人的好友集合`。
4. 输出按推荐分**降序**；分数相同时按候选人名字**字典序升序**。
5. 每位候选人同时给出共同好友名单，名单按名字升序。

若 `target` 不在关系表中（没有任何好友），返回空列表。

### 输入 / 输出约定

```python
def recommend_friends(relations: list[str], target: str) -> list[tuple[str, list[str]]]:
    ...
```

- `relations`: 关系字符串列表，每项形如 `"名字-名字"`（名字内部不含 `-`）
- `target`: 目标用户名字
- 返回: `[(候选人, [共同好友, ...]), ...]`，按上述排序规则，共同好友名单升序

### 样例

样例 1 — 常规场景:

```python
relations = ["alice-bob", "alice-carol", "bob-dave", "carol-dave", "dave-erin", "bob-erin"]
recommend_friends(relations, "alice")
# dave 的共同好友 = {bob, carol} → 2 分; erin 的共同好友 = {bob} → 1 分
# 返回 [("dave", ["bob", "carol"]), ("erin", ["bob"])]
```

样例 2 — 单边关系 + 自环 + 重复关系:

```python
relations = ["tom-tom", "tom-jerry", "jerry-tom", "spike-tom", "spike-tyke"]
recommend_friends(relations, "tom")
# tom 的好友 = {jerry, spike}; 候选人只剩 tyke
# 返回 [("tyke", ["spike"])]
```

样例 3 — 同分按名字排序 + 未知用户:

```python
relations = ["z-a", "z-b", "a-m", "b-n", "n-n"]
recommend_friends(relations, "z")       # m 与 n 都是 1 分 → [("m", ["a"]), ("n", ["b"])]
recommend_friends(relations, "ghost")   # 该用户不在关系表里 → []
```

### 实现要求

- 必须用 `set` 的交/并/差运算求共同好友，禁止双重循环逐对比较"数共同好友"
- 排序用一次 `sorted(..., key=lambda x: (-len(x[1]), x[0]))` 完成
- 邻接表用 `defaultdict(set)` 构建，关系表可能有上万条，整体复杂度接近 O(E + Σ候选人好友数)
- 函数内不要 `print`，直接 `return`
